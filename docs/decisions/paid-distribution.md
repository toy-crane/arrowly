# 유료 배포

## Decisions

- Arrowly는 일회성 구매로 판매한다. 결제와 설치 파일 전달은 Polar가 맡고, 구매자는 Polar에서 서명·공증된 DMG를 내려받는다.
- 앱은 구매 여부를 확인하지 않는다. 라이선스 키 입력·검증, 체험 기간, 기능 제한과 이를 위한 네트워크 통신을 두지 않는다.
- 구매에는 이후 출시하는 모든 버전이 포함된다. 기존 구매자는 추가 결제 없이 같은 구매로 새 버전을 내려받는다.
- 소스 저장소는 공개로 유지하고 오픈소스 라이선스를 부여하지 않는다. 공개 GitHub Releases를 포함한 공개 경로에는 설치 파일(DMG, 앱 압축본)을 두지 않는다.
- 이미 무료로 배포된 사본은 회수하거나 비활성화하지 않는다.

## Boundaries

- 저장소 소스를 직접 빌드하는 경로는 막지 않는다. 판매 대상은 서명·공증된 설치 파일이다.
- 가격, 환불 기간, 상품 설명 같은 판매 조건은 이 계약이 아니라 Polar 상품 설정과 해당 작업 스펙이 소유한다.

## Why

수요 근거가 거의 없는 상태에서 판매를 시작하는 공수를 최소화한다. 앱에 라이선스 검증을 넣으면 네트워크 통신, 키 저장, 오프라인 처리와 검증 실패 시 사용을 막는 경로가 새로 생기고, 강의 중 앱이 막히는 실패 상태가 추가된다. 결제 뒤 다운로드만 제한하면 앱을 바꾸지 않고 판매할 수 있으며, 설치 파일의 무단 공유는 감수한다. 앱이 구매 상태를 확인하지 않으면 해지 뒤에도 앱이 계속 동작하므로 구독은 성립하지 않는다.

Polar는 웹사이트 없이 판매를 시작할 수 있고(계정 심사는 첫 정산 전), 한국을 정산 국가로 지원하며, 파일 전달과 기존 구매자에 대한 새 파일 제공, 원화 결제창의 국내 간편결제를 제공한다. 이후 라이선스 키가 필요해져도 인증 없이 앱에서 호출할 수 있는 검증 API가 있어 서버 없이 확장할 수 있다.

저장소를 공개로 두면 README와 이슈를 제품 소개와 문의 창구로 계속 쓰고 macOS CI 비용이 생기지 않는다.

## Reconsider when

- 무단 공유된 설치 파일이 구매를 대체한다는 증거가 생긴다.
- 구매 전 체험 요구나 환불 요청이 반복된다.
- 해외 결제 카드가 없는 국내 구매자의 결제 실패가 반복된다.
- Polar가 한국 정산을 중단하거나, Stripe Connect Express에 한국 법인이 가입할 수 없다고 확인된다.
- 유료 메이저 업그레이드나 구독이 필요해진다.

## Still-rejected alternatives

- 앱 내 라이선스 키 검증과 체험 기간 — 네트워크·키 저장·사용 차단 실패 상태가 생기고 수요 근거 전에는 공수 대비 이익이 없다. 무단 공유나 체험 요구의 증거가 생기면 재검토한다.
- 구독 — 앱이 구매 상태를 확인하지 않아 해지가 의미 없다. 라이선스 검증을 도입하면 재검토한다.
- Mac App Store — 투명 웹뷰가 macOS 비공개 API에 의존하고 샌드박스 밖에서 동작한다. 공개 API만으로 같은 오버레이를 구현할 수 있게 되면 재검토한다.
- Setapp — 단일 앱 판매가 한국 개발자를 받지 않고, Setapp 프레임워크 연동이 필수이며, Tauri 앱 경로가 문서화되어 있지 않다.
- Lemon Squeezy — 한국이 빠진 Stripe Managed Payments로 이전 중이라 판매 경로를 잃을 수 있다.
- Gumroad — 수수료가 10% + 50¢로 가장 높다. Polar 정산이 막히면 대안 후보지만 한국 법인의 원화 정산은 공식 문서로 확인하지 못했다.
- Paddle·Creem — 약관·환불·개인정보 정책을 갖춘 웹사이트 심사가 필요하다. Paddle은 파일 전달을 제공하지 않는다.
- 국내 PG 직접 결제 — 통신판매업 신고와 부가세를 직접 처리해야 한다.
- 저장소 비공개 전환 — README·이슈 창구를 잃고 macOS CI 비용이 생긴다.
- 기존 무료 설치 파일의 공개 다운로드 유지 — 현재 버전으로도 충분히 쓸 만해 구매 동기가 약해진다.

## Evidence worth preserving

- 2026-10-14 Polar 공식 문서 확인: 정산 국가 목록에 한국 포함(Stripe Connect Express 경유, 법인 가입 여부는 국가 단위로만 명시), 계정 심사는 첫 정산 전 최대 14일, 웹사이트는 권장 사항, 파일당 10GB와 추가 파일의 기존 구매자 소급 제공, 삭제한 파일은 기존 구매자 접근도 회수, 원화 결제창에서 카카오페이·네이버페이·삼성페이 제공. Starter 수수료 5% + 50¢, 미국 외 카드 +1.5%, Stripe 정산 비용 별도.
- 2026-10-14 확인: Lemon Squeezy 공식 블로그가 사용자를 Stripe Managed Payments로 옮기는 것을 목표로 밝혔고, Stripe Managed Payments의 사업자 국가 목록(북미 2개국, 유럽, AU·HK·JP·SG)에 한국이 없다.
