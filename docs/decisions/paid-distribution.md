# 유료 배포

## Decisions

- Arrowly는 Mac App Store에서 일회성 구매로 판매하는 것을 우선한다. 첫 제출을 심사 게이트로 삼아, 현재 투명 오버레이 구현을 유지한 판매 가능한 빌드가 심사를 통과하는지 먼저 확인한다.
- 게이트가 비공개 API 사용이나 샌드박스에서 유지할 수 없는 핵심 동작 때문에 실패하면, App Store 진입을 위해 오버레이를 다시 만들지 않고 Polar 직판으로 판매한다. Polar 직판에서는 구매자가 결제 뒤 Polar에서 서명·공증된 DMG를 내려받는다.
- 가격은 일회성 구매이며 구매에는 이후 출시하는 모든 버전이 포함된다.
- 앱은 라이선스 키 입력·검증, 체험 기간, 기능 제한을 두지 않는다.
- 소스 저장소는 공개로 유지하고 오픈소스 라이선스를 부여하지 않는다. 판매를 시작하면 공개 GitHub Releases를 포함한 공개 경로에 설치 파일(DMG, 앱 압축본)을 두지 않는다.
- 이미 무료로 배포된 사본은 회수하거나 비활성화하지 않는다.

## Boundaries

- 저장소 소스를 직접 빌드하는 경로는 막지 않는다. 판매 대상은 서명된 설치 본이다.
- 가격, 판매 국가, 스토어 설명 같은 판매 조건은 이 계약이 아니라 스토어 설정과 해당 작업 스펙이 소유한다.
- App Store 빌드의 샌드박스 대응(로그인 시 실행 방식 등)은 기존 오버레이·단축키 결정의 사용자 동작을 바꾸지 않는 범위에서만 한다.

## Why

판매를 운영하는 공수를 최소화한다. App Store는 결제, 세금, 환불, 국내 구매자 결제, 자동 업데이트를 Apple이 처리하고 검색 노출을 제공한다. 수요 근거가 거의 없는 지금은 노출이 가장 부족한 요소다. Apple Developer 계정도 이미 있다.

App Store 진입 비용의 가장 큰 미지수는 투명 오버레이다. 웹뷰 배경을 투명하게 만드는 설정이 비공개 API이고 심사 지침 2.5.1은 공개 API만 허용하지만, 같은 상황의 Tauri 앱이 통과하거나 거절된 보고는 없다. 실제 제출 외에는 확인할 방법이 없으므로 첫 제출을 게이트로 둔다. 게이트가 실패했을 때 오버레이를 네이티브로 다시 만드는 비용은 앱의 핵심을 다시 짜는 수준이라, 앱을 바꾸지 않고 바로 팔 수 있는 Polar 직판을 대안으로 둔다.

앱에 라이선스 검증을 넣으면 네트워크 통신, 키 저장, 오프라인 처리와 강의 중 앱이 막히는 실패 상태가 새로 생긴다. 앱이 구매 상태를 확인하지 않으므로 무단 공유는 감수한다. 저장소를 공개로 두면 README와 이슈를 제품 소개와 문의 창구로 계속 쓰고 macOS CI 비용이 생기지 않는다.

## Reconsider when

- 무단 공유된 설치 본이 구매를 대체한다는 증거가 생긴다.
- 구매 전 체험 요구나 환불 요청이 반복된다.
- 유료 메이저 업그레이드나 구독이 필요해진다.
- App Store 판매 중 이후 업데이트가 비공개 API를 이유로 거절된다.
- Polar 직판으로 간 뒤, 판매가 확인되고 노출 부족이 병목이라는 증거가 생긴다.

## Still-rejected alternatives

- 게이트 실패 시 오버레이를 네이티브로 다시 만들어 App Store에 진입 — 앱 핵심 재작성 비용이 수요 근거보다 크다. 직판 매출로 App Store 노출의 필요가 확인되면 재검토한다.
- 앱 내 라이선스 키 검증과 체험 기간 — 네트워크·키 저장·사용 차단 실패 상태가 생기고 수요 근거 전에는 공수 대비 이익이 없다. 무단 공유나 체험 요구의 증거가 생기면 재검토한다.
- 구독 — 앱이 구매 상태를 확인하지 않아 성립하지 않는다.
- Setapp — 단일 앱 판매가 한국 개발자를 받지 않고, Setapp 프레임워크 연동이 필수이며, Tauri 앱 경로가 문서화되어 있지 않다.
- Lemon Squeezy — 한국이 빠진 Stripe Managed Payments로 이전 중이라 판매 경로를 잃을 수 있다.
- Gumroad — 수수료가 10% + 50¢로 가장 높다. 한국 법인의 원화 정산은 공식 문서로 확인하지 못했다.
- Paddle·Creem — 약관·환불·개인정보 정책을 갖춘 웹사이트 심사가 필요하다. Paddle은 파일 전달을 제공하지 않는다.
- 국내 PG 직접 결제 — 통신판매업 신고와 부가세를 직접 처리해야 한다.
- 저장소 비공개 전환 — README·이슈 창구를 잃고 macOS CI 비용이 생긴다.
- 기존 무료 설치 파일의 공개 다운로드 유지 — 현재 버전으로도 충분히 쓸 만해 구매 동기가 약해진다.

## Evidence worth preserving

- 2026-10-14 확인: wry 0.55.1은 투명 웹뷰를 위해 `WKWebViewConfiguration`의 `drawsBackground`를, 전체화면 지원을 위해 `WKPreferences`의 `fullScreenEnabled`를 KVC로 설정하며, 두 곳 모두 소스 주석에 비공개 API라고 표시한다. Tauri 2.12.1부터는 이 설정이 기능 플래그 없이 항상 켜진다. 한쪽만 제거해서는 비공개 API 사용이 없어지지 않는다.
- 2026-10-14 확인: App Review Guidelines 2.5.1은 공개 API만 허용하고, 2.4.5는 Mac App Store 앱에 샌드박스와 동의 없는 로그인 시 자동 실행 금지를 요구한다. 2019년 Electron 앱이 프레임워크 내부의 비공개 API 호출로 자동 심사에서 거절된 선례가 있고, 당시 집행은 일관되지 않았다.
- 2026-10-14 확인: App Store 소규모 사업자 프로그램 수수료는 15%(전년도 수익 100만 달러 이하).
- 2026-10-14 Polar 공식 문서 확인: 정산 국가 목록에 한국 포함(Stripe Connect Express 경유, 법인 가입 여부는 국가 단위로만 명시), 계정 심사는 첫 정산 전 최대 14일, 웹사이트는 권장 사항, 파일당 10GB와 추가 파일의 기존 구매자 소급 제공, 삭제한 파일은 기존 구매자 접근도 회수, 원화 결제창에서 카카오페이·네이버페이·삼성페이 제공. Starter 수수료 5% + 50¢, 미국 외 카드 +1.5%, Stripe 정산 비용 별도.
- 2026-10-14 확인: Lemon Squeezy 공식 블로그가 사용자를 Stripe Managed Payments로 옮기는 것을 목표로 밝혔고, Stripe Managed Payments의 사업자 국가 목록(북미 2개국, 유럽, AU·HK·JP·SG)에 한국이 없다.
- 2026-10-15 확인: 공개 저장소의 GitHub Actions 아티팩트는 비로그인 요청에는 401을 돌려주지만, 저장소와 무관한 GitHub 계정으로 로그인하면 200으로 내려받아진다. 아티팩트는 공개 경로로 본다.
- 2026-10-15 확인: App Store 등록 정보의 지원·마케팅·개인정보 처리방침 URL이 모두 이 저장소를 가리켜, 비공개로 전환하면 세 링크가 열리지 않는다.
