# 도구와 마크 상호작용 모델

## Decisions

- 자유곡선·끝점 화살표·사각형·타원·삼각형은 플로팅 마커에서 명시적으로 선택하는 그리기 도구다. 사용 빈도가 낮은 도구 선택에 직접 키보드 단축키를 두지 않으며, 선택한 기하 도구는 같은 그리기 세션에서 다른 도구를 고를 때까지 유지된다.
- 자유곡선은 사용자가 획 끝을 오래 멈춰 요청할 때만 화살촉 없는 직선이나 닫힌 도형으로 보정한다. 별도 직선 도구, 자유곡선 화살표 자동 인식과 Shift 방향 제한은 두지 않는다.
- 텍스트 도구는 기억한 그리기 도구를 대체하지 않는다. 새 텍스트 작성이나 기존 텍스트 교정이 끝나면 이전 그리기 도구로 돌아간다.
- 확대 도구는 플로팅 마커에서 마크 삭제 다음과 블랙보드 구분선 앞에 놓는 잠금 도구다. 선택 즉시 커서 주변 확대를 시작하고 별도 속성 패널을 열지 않으며, 기억한 그리기 도구를 바꾸지 않는다.
- 모든 확정 마크는 이동, 복제와 삭제에 같은 후보 표시와 hit-test를 사용하며, 겹친 곳에서는 가장 위의 마크 하나를 대상으로 한다.
- 이동과 순간 삭제는 옮기기 키(기본 `⌘`)·지우기 키(기본 `⌥`)로 잠시 드러나는 탐색 상태에서 수행하고 지속적인 선택을 남기지 않는다. 플로팅 마커 삭제 버튼은 같은 삭제 상호작용을 잠그는 발견성 경로다. 키 설정 규칙은 [단축키 범위와 소유권](shortcut-policy.md)이 소유한다.
- 마크 복제는 옮기기 키와 복제 추가 키(기본 `⌥`)를 함께 누른 복제 탐색 상태에서 마크를 끌어 수행한다. 누른 순서와 관계없이 두 키가 함께 눌리면 복제이고, 이동인지 복제인지는 놓는 순간 복제 추가 키가 눌려 있는지로 정한다.
- 복제 탐색 상태에서 옮기기 키만 먼저 떼서 남은 키가 지우기 키이면 삭제 탐색으로 넘어가지 않고 모든 키를 뗄 때까지 멈춘다. 복제하려다 손을 떼는 중에 마크가 지워지지 않게 하기 위해서다.
- 새 마크, 마크 복제, 마크 이동, 텍스트 교정과 마크 삭제는 각각 실행 취소 한 단위이며 원래 z-order를 보존한다. 복제본은 가장 위에 놓인다.

## Why

강의 중에는 같은 표시를 반복해서 만드는 직접 도구와 잘못 놓은 마크 하나를 즉시 고치는 제스처가 필요하다. 이미 그린 표시를 다른 곳에 한 번 더 놓을 때도 선택이나 클립보드 없이 이동 제스처에 키 하나를 더하는 구조가 가장 적게 배운다. 기본값 `⌥`는 macOS 관례와 같다. 확대도 영역 선택이나 설정 단계를 요구하면 설명 흐름을 끊으므로 다른 잠금 도구와 같은 1층에서 바로 시작한다. 지속적인 선택·핸들·모드 전환은 조작 상태를 늘린다. 이동과 삭제가 같은 표적화 모델을 공유하면 화면에 보이는 후보와 실제 동작이 어긋나지 않는다.

## Boundaries

- 텍스트는 내용과 크기를 교정할 수 있지만 일반적인 객체 선택 상태를 만들지 않는다.
- 구체적인 시간·거리 임계값, 팔레트, 굵기와 크기 단계는 코드와 테스트가 소유한다.
- 확대 도구는 마크나 실행 취소 이력을 만들지 않으며, 블랙보드 배경 상태와 독립적으로 활성 상태를 유지한다.
- 수식키 전달과 비활성 NSPanel의 포인터 동작은 실제 macOS 앱에서 검증한다.

## Reconsider when

- 순간 탐색보다 지속 도구가 반복 작업을 더 빠르게 만든다는 사용 근거가 쌓인다.
- 자유곡선 보정과 명시적 기하 도구가 같은 의도를 중복해 혼란을 만든다는 관찰이 반복된다.
- 현재 hit-test가 조밀하게 겹친 마크에서 뒤쪽 대상을 사실상 선택할 수 없게 한다.
- 삭제하려고 지우기 키를 누른 중에 옮기기 키를 건드려 복제 탐색으로 바뀌는 혼란이 반복된다.
- 키를 바꿀 수 있게 한 뒤에도 수식키 누름을 전역으로 쓰는 앱과의 충돌 보고가 반복된다.
- 고정 `2×` 가로형 렌즈가 실제 강의에서 작은 글자와 조작부를 충분히 읽히게 하지 못한다는 관찰이 반복된다.

## Still-rejected alternatives

- 지속적인 선택·이동 모드와 선택 핸들
- 한 번 그린 뒤 자유곡선으로 자동 복귀하는 일회성 기하 도구
- 별도 직선 도구와 자유곡선 화살표 자동 인식
- 수평·수직·45도 방향 제한
- 부분 지우개와 드래그 연속 삭제
- 커서 아래 마크를 `⌘C`로 담고 `⌘V`로 붙이는 복제: 무엇이 담겼는지 보이지 않는 클립보드 상태를 만든다.
- 커서 아래 마크를 `⌘D`로 제자리 근처에 복제: 놓은 뒤 다시 옮겨야 한다.
- 복제 탐색에서 `⌘`를 먼저 떼면 바로 삭제 탐색으로 넘어가는 방식
