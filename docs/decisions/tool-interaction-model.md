# 도구와 마크 상호작용 모델

## Decisions

- 자유곡선·끝점 화살표·사각형·타원·삼각형은 플로팅 마커에서 명시적으로 선택하는 그리기 도구다. 사용 빈도가 낮은 도구 선택에 직접 키보드 단축키를 두지 않으며, 선택한 기하 도구는 같은 그리기 세션에서 다른 도구를 고를 때까지 유지된다.
- 자유곡선은 사용자가 획 끝을 오래 멈춰 요청할 때만 화살촉 없는 직선이나 닫힌 도형으로 보정한다. 별도 직선 도구, 자유곡선 화살표 자동 인식과 Shift 방향 제한은 두지 않는다.
- 텍스트 도구는 기억한 그리기 도구를 대체하지 않는다. 새 텍스트 작성이나 기존 텍스트 교정이 끝나면 이전 그리기 도구로 돌아간다.
- 모든 확정 마크는 이동과 삭제에 같은 후보 표시와 hit-test를 사용하며, 겹친 곳에서는 가장 위의 마크 하나를 대상으로 한다.
- 이동과 순간 삭제는 `⌘`·`⌥`로 잠시 드러나는 탐색 상태에서 수행하고 지속적인 선택을 남기지 않는다. 플로팅 마커 삭제 버튼은 같은 삭제 상호작용을 잠그는 발견성 경로다.
- 새 마크, 마크 이동, 텍스트 교정과 마크 삭제는 각각 실행 취소 한 단위이며 원래 z-order를 보존한다.

## Why

강의 중에는 같은 표시를 반복해서 만드는 직접 도구와 잘못 놓은 마크 하나를 즉시 고치는 제스처가 필요하다. 지속적인 선택·핸들·모드 전환은 조작 상태를 늘린다. 이동과 삭제가 같은 표적화 모델을 공유하면 화면에 보이는 후보와 실제 동작이 어긋나지 않는다.

## Boundaries

- 텍스트는 내용과 크기를 교정할 수 있지만 일반적인 객체 선택 상태를 만들지 않는다.
- 구체적인 시간·거리 임계값, 팔레트, 굵기와 크기 단계는 코드와 테스트가 소유한다.
- 수식키 전달과 비활성 NSPanel의 포인터 동작은 실제 macOS 앱에서 검증한다.

## Reconsider when

- 순간 탐색보다 지속 도구가 반복 작업을 더 빠르게 만든다는 사용 근거가 쌓인다.
- 자유곡선 보정과 명시적 기하 도구가 같은 의도를 중복해 혼란을 만든다는 관찰이 반복된다.
- 현재 hit-test가 조밀하게 겹친 마크에서 뒤쪽 대상을 사실상 선택할 수 없게 한다.

## Still-rejected alternatives

- 지속적인 선택·이동 모드와 선택 핸들
- 한 번 그린 뒤 자유곡선으로 자동 복귀하는 일회성 기하 도구
- 별도 직선 도구와 자유곡선 화살표 자동 인식
- 수평·수직·45도 방향 제한
- 부분 지우개와 드래그 연속 삭제
