# 단축키 범위와 소유권

## Decisions

- 그리기 토글과 블랙보드 토글만 상시 전역 등록한다. 전체 지우기와 텍스트 진입은 그리기 모드에서 오버레이가 처리한다.
- 그리기, 블랙보드, 전체 지우기와 텍스트 네 동작은 사용자가 재설정할 수 있다. Esc, Undo/Redo, 이동·삭제 제스처, 삭제 도구, 도구 크기와 색 선택은 고정 조작이다.
- 전역 단축키에는 수식키가 필요하다. 오버레이가 처리하는 로컬 텍스트 단축키는 수식키 없는 키를 허용한다.
- Esc와 표준 `⌘Z` 계열, Arrowly 고정 조작과 내부 중복 조합은 사용자 단축키로 허용하지 않는다. 수정자 없는 `C`는 빠른 색 팔레트가 소유하며, 텍스트에 `C`를 쓰던 기존 설정은 기본 텍스트 키로 마이그레이션한다. `E`는 더 이상 예약하지 않는다.
- 전역 등록 실패는 조용히 무시하지 않고 해당 설정에서 원인과 해결 방법을 보여준다.

## Why

화면 밖에서도 진입해야 하는 동작만 전역으로 소유하면 다른 앱과의 충돌 범위를 줄일 수 있다. 편집과 복구에 익숙한 OS 표준 키와 Arrowly의 핵심 제스처를 고정하면 설정이 탈출·Undo·삭제 경로를 깨뜨리지 않는다.

## Boundaries

- 기본 accelerator와 검증 규칙의 실행 가능한 단일 소스는 `src-tauri/src/shortcut_policy.rs`다.
- 설정 스키마와 마이그레이션은 `src/shared/settings.ts`와 `src-tauri/src/store.rs`를 함께 바꾼다.
- 다른 앱 내부 단축키와의 의미 충돌은 미리 감지할 수 없다.

## Reconsider when

- 반복적인 실제 충돌 데이터가 현재 기본값이나 고정 키를 부적절하게 만든다.
- macOS가 앱 비활성 상태의 로컬 키 전달 또는 전역 단축키 등록 방식을 바꾼다.

## Still-rejected alternatives

- 모든 판서 동작을 상시 전역 단축키로 등록하는 방식
- Esc, Undo/Redo와 이동·삭제 수식키까지 사용자 설정으로 여는 방식
- 접근성 이벤트 탭으로 다른 앱의 키 입력을 가로채는 방식
