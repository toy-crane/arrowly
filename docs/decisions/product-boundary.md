# 제품 경계

## Decisions

- Arrowly는 강의 중 정지된 화면 한 장면에 즉석으로 쓰고 지우는 macOS 주석 오버레이다. 저장·배치·정렬하는 문서 편집기가 아니다.
- 마크와 블랙보드 상태는 앱 재시작 뒤 복원하지 않는다. 사용자 설정만 영속화한다.
- 모든 확정 마크는 위치를 한 번에 교정할 수 있다. 텍스트 마크만 내용과 텍스트 크기도 교정하며, 펜 경로와 직선·도형의 기하는 삭제 후 다시 그린다.
- 마크 이동은 지속적인 선택을 만들지 않는 일회성 제스처다. 여러 마크를 선택하거나 관리하는 객체 모델을 만들지 않는다.
- 포인터 핑은 마크나 이력으로 남지 않는 일시적 강조다.
- 한 번에 커서가 있는 모니터 하나만 다룬다. 마크는 화면 좌표에만 존재하며 다른 모니터로 작업 대상을 바꾸면 기존 마크를 지운다.

## Why

강의 흐름을 깨지 않고 한 장면을 설명한 뒤 비우는 것이 제품의 중심 작업이다. 준비와 재사용은 슬라이드가 담당한다. 장기 상태, 선택, 정렬과 기하 편집은 입력 비용과 실패 상태를 늘리므로 라이브 상황에서 얻는 이익보다 관리 부담이 크다.

## Boundaries

- 자유곡선, 소수의 기하 마크, 텍스트와 블랙보드로 한 장면을 설명하는 기능은 범위 안이다.
- 잘못 놓은 마크 하나의 위치를 옮기거나 전체를 삭제하는 국소 교정은 범위 안이다.
- 통과 모드로 나가면 마크는 숨지만 현재 세션에서는 삭제되지 않는다.

## Reconsider when

- 사용자가 강의 전에 판서를 준비하거나 여러 장면을 반복해서 복원해야 한다는 증거가 쌓인다.
- 삭제 후 다시 그리기가 강의 흐름을 반복적으로 끊는 구체적인 기하 교정 사례가 확인된다.
- 한 사용자가 여러 모니터에 동시에 판서해야 하는 반복 작업이 확인된다.

## Still-rejected alternatives

- 마크 저장·불러오기, 여러 페이지와 판서 사전 준비
- 지속적인 선택 상태, 여러 마크 선택·그룹·정렬·스냅
- 펜 경로와 직선·도형의 핸들 기반 기하 편집, 부분 지우개
- 아래 화면 스크롤 추적, 여러 모니터 동시 오버레이
- 통과 모드에서 마크를 계속 표시하는 동작
