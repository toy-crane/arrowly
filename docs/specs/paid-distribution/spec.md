# Polar 유료 판매 전환

## 목적

앱을 바꾸지 않고 Arrowly를 $14.99 일회성 구매로 판매하기 시작한다. 결제한 사람만 서명·공증된 설치 파일을 받고, 이후 버전도 같은 구매로 받는다.

## 관련 소스

- [docs/decisions/paid-distribution.md](../../decisions/paid-distribution.md) — 일회성 구매, Polar 결제·전달, 앱의 구매 비확인, 공개 저장소와 설치 파일 비공개의 기준. 이 스펙은 그 계약을 적용하는 판매 조건과 전환 절차만 정한다.
- [docs/decisions/product-boundary.md](../../decisions/product-boundary.md) — 앱 기능 범위. 이 작업은 앱 기능을 바꾸지 않는다.

## 확정된 경험

### 잠재 구매자

- README 첫 화면에서 지금의 다운로드 링크 자리에 가격($14.99), 일회성 구매, 이후 업데이트 포함, 환불 조건과 Polar 구매 링크를 보여 준다.
- 구매 링크는 Polar 운영 체크아웃으로 이어지고 USD $14.99를 표시한다. 국내외 구매자 모두 해외 결제가 가능한 카드로 결제한다.
- README, GitHub Releases와 그 밖의 공개 경로 어디에서도 설치 파일(DMG, 앱 압축본)을 직접 받을 수 없다.
- README의 소개, 기능, 조작 안내, 이슈 링크와 개발·빌드 안내는 유지한다.

### 구매 직후

- 결제를 마친 구매자는 Polar가 보내는 구매 확인과 고객 포털에서 `Arrowly_<버전>_universal.dmg`를 내려받는다.
- 내려받은 DMG는 지금과 같은 Developer ID 서명·공증 빌드다. Applications로 옮겨 실행하면 Gatekeeper 경고 없이 열리고 첫 사용 튜토리얼이 시작된다.
- README의 설치 안내는 첫 단계를 "구매 후 고객 포털에서 DMG 받기"로 바꾸고 나머지 설치 단계는 유지한다.
- 앱 안에는 구매·라이선스·체험 기간 관련 화면, 입력, 안내와 네트워크 요청이 없다.

### 새 버전 출시

- 새 버전을 출시하면 기존 구매자는 추가 결제 없이 같은 고객 포털에서 새 DMG를 받는다.
- 고객 포털의 설치 파일을 교체하는 동안에도 기존 구매자가 받을 수 있는 설치 파일이 하나 이상 있다.
- 앱은 새 버전을 알리지 않는다. 자동 업데이트 없음은 그대로다.
- 릴리스 담당자의 게시 절차는 다음 상태에 도달해야 끝난다.
  - 서명·공증 검증을 통과한 새 DMG가 Polar 상품의 다운로드 파일로 제공된다.
  - 해당 버전의 공개 GitHub Release에는 설치 파일 에셋이 없다.
- 태그 push로 CI가 draft Release에 서명·공증 빌드를 만드는 단계는 지금과 같다.

### 전환 순서

- 공개 설치 파일을 내리고 README 링크를 바꾸는 일은 Polar 운영 구매 링크에서 결제와 다운로드가 동작하는 것을 확인한 뒤에 한다. 전환 중 앱을 얻을 경로가 하나도 없는 시점이 생기지 않게 한다.
- v0.1.0-beta부터 v0.4.0까지 모든 공개 릴리스의 설치 파일 에셋을 내린다. 릴리스 항목과 변경 내역은 남긴다.

### 기존 무료 사용자

- 이미 받은 v0.4.0 이하 사본은 계속 동작한다. 별도 안내, 비활성화, 회수는 하지 않는다.

## 인수 조건

- 공개 GitHub Releases 전체에서 `.dmg`와 `.app.tar.gz` 에셋이 0개다.
- README에 가격, 일회성 구매, 업데이트 포함, 환불 조건과 Polar 구매 링크가 보이고, 설치 파일을 직접 내려받는 링크가 없다.
- README 구매 링크를 열면 Polar 운영 체크아웃이 열리고 $14.99 일회성 상품으로 표시된다.
- Polar 샌드박스에서 테스트 카드로 같은 구성의 상품을 구매하면 구매 확인과 고객 포털에서 현재 버전 DMG를 받을 수 있다.
- 고객 포털에서 받은 DMG의 앱이 `spctl` 검사에서 accepted와 Notarized Developer ID로 판정되고, 스테이플 검증을 통과하며, Team ID가 지금 릴리스와 같다.
- 게시 절차로 새 버전을 올린 뒤, 그 전에 구매한 샌드박스 구매자가 고객 포털에서 새 버전 DMG를 받을 수 있고, 해당 공개 Release에는 설치 파일 에셋이 없다.
- 운영 Polar 상품의 다운로드 파일은 현재 출시 버전의 DMG 하나다.
- 앱 소스와 앱 설정이 바뀌지 않는다. 같은 버전의 앱 동작은 전환 전과 같다.

## 확정된 제약

- 가격은 USD $14.99 일회성이다. 기능을 갖춘 발표용 주석 앱이 $12.99–$14.99에 모여 있고(Presentify, Annotate Screen, Keystroke Pro, Cursor Pro, SketchMouse), Presentify가 Polar 직판으로 $14에 판매 중이다(2026-10-14 확인).
- 구매자는 국내외를 모두 대상으로 하고 해외 결제 가능 카드를 기준으로 한다. 국내 간편결제나 해외결제가 막힌 국내 카드가 필요한 구매자는 놓칠 수 있음을 받아들인다.
- 구독, 앱 내 라이선스 확인, 저장소 비공개 전환, 오픈소스 라이선스 추가는 하지 않는다. 이유는 결정 계약을 따른다.

## 가정

다음은 되돌리기 쉬워 에이전트가 정한 기본값이며 사용자가 바꿀 수 있다.

- 환불: 구매 후 14일 이내 요청하면 이유를 묻지 않고 전액 환불한다. 체험판이 없는 것을 보완한다. Polar도 차지백을 막기 위해 60일 안에 판매자 의사와 관계없이 환불할 수 있다.
- 고객 포털에는 최신 버전 DMG 하나만 둔다. 이전 버전은 제공하지 않는다.
- 공개 GitHub Release는 설치 파일 없이 변경 내역만 공개한다.
- Polar 상품 이름은 "Arrowly", 설명은 영어를 기본으로 한국어를 함께 적고 README의 소개 문구를 재사용한다.
- Polar 요금제는 Starter(5% + 50¢, 미국 외 카드 +1.5%)로 시작한다.

## 비범위

- 앱 안의 구매 안내, 라이선스 키 입력·검증, 체험 기간, 업데이트 확인과 네트워크 통신 — 결정 계약이 금지한다.
- 별도 웹사이트나 랜딩 페이지 — README와 Polar 체크아웃으로 대신한다. Polar 심사가 웹사이트를 요구하면 다시 정한다.
- Polar SDK, 웹훅, 서버 — 코드 연동 없이 대시보드와 체크아웃 링크만 쓴다.
- 할인 코드, 교육·지역별 가격, 팀·사이트 라이선스.
- 기존 무료 사본 회수와 기존 사용자 대상 공지.
- 유입 확대(홍보, 마케팅) — 이 스펙은 판매 경로만 다룬다.

## 보류한 결정

- 원화(KRW) 가격과 국내 간편결제: 카카오페이·네이버페이·삼성페이는 원화 가격 결제창에서만 나타나는데, 한 상품에 USD와 KRW 가격을 함께 둘 수 있는지 확인하지 못했다. 보류 동안(interim) USD $14.99 단일 가격으로 판매하고 Polar 기본 결제 수단만 제공한다. Polar 상품을 만들 때 원화 가격 설정 가능 여부를 확인한 뒤 원화 가격 결정으로 대체한다.
- 새 버전 출시 알림: Polar가 다운로드 파일을 추가할 때 기존 구매자에게 알림을 보내는지 확인하지 못했다. 보류 동안(interim) 별도 알림 없이 README와 공개 Release 변경 내역으로만 알린다. 알림이 필요해지면 Polar 알림 기능 확인 뒤 정한다.
- 유료 메이저 업그레이드: 보류 동안(interim) 모든 이후 버전을 같은 구매에 포함한다. 유료 업그레이드는 결정 계약의 재검토 조건이 충족될 때 정한다.
- 설치 파일 업로드 자동화(Polar API·MCP): 보류 동안(interim) 릴리스 담당자가 Polar 대시보드에서 직접 올린다. 릴리스 빈도가 늘거나 업로드 실수가 생기면 정한다.

## 남은 위험

- Polar 문서는 한국을 국가 단위로만 지원한다고 밝힌다. Stripe Connect Express에 한국 법인이 실제로 가입하지 못하면 정산을 받을 수 없고, 결정 계약에 따라 Gumroad를 다시 검토해야 한다.
- Polar 계정 심사(첫 정산 전, 최대 14일) 결과가 정해지지 않았다. 심사 중에도 판매는 되지만 정산은 보류된다.
- 해외 결제가 막힌 국내 카드를 쓰는 구매자는 결제하지 못한다.
- 설치 파일 무단 공유와 공개 소스 직접 빌드를 막지 않는다.
- 체험판이 없어 구매 전환이 낮을 수 있다. 환불 조건으로만 보완한다.
- 릴리스별 다운로드가 1–3회 수준이라 판매 경로보다 유입이 병목일 수 있다. 판매를 시작해도 구매가 없을 수 있다.
- Polar에서 다운로드 파일을 삭제하면 기존 구매자의 접근도 회수된다. 교체 순서를 지키지 않으면 구매자가 받을 파일이 없는 시점이 생긴다.
- 통신판매업 신고 필요 여부와 Polar 정산금의 국내 매출 처리 방식을 확인하지 않았다.

## Setup before implementation

- ODD Inc. 명의 Polar 운영 조직과 판매자 정보 제출 — 운영 체크아웃 판매 — Polar 대시보드 Finance → Account에 조직 정보 제출이 완료된 상태다.
- Stripe Connect Express 정산 계정(한국 법인 계좌)과 소유자 신원 확인 — 판매 대금 정산 — Polar 대시보드에 정산 계정이 연결된 것으로 표시된다. 가입이 거부되면 구현 전에 결정 계약을 재검토한다.
- Polar 샌드박스 조직 — 구매·다운로드·버전 교체 인수 조건 검증 — `sandbox.polar.sh`에 조직이 있고 상품을 만들 수 있다.
- 국내 세무 확인 — MoR 판매의 통신판매업 신고 필요 여부와 정산금 매출 처리 — 세무 대리인의 답변을 받았거나 필요한 신고를 마친 상태다.
