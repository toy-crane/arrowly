# 빠른 색 선택

## 목적

판서할 위치에서 멀리 벗어나지 않고 실제 색을 보며 다음 마크의 잉크 색을 고른다. 색마다 키를 외우거나 플로팅 마커까지 포인터를 왕복하지 않는다.

## 빠른 색 팔레트

- 그리기 모드에서 수정자 없는 로컬 키 `C`를 누르면 키를 누른 순간의 포인터 가까이에 [빠른 색 팔레트](../../../GLOSSARY.md)를 연다.
- 빠른 색 팔레트는 플로팅 마커의 도구 속성 패널에 이미 쓰는 색 선택 줄을 그대로 재사용한다. 옐로우·오렌지·핑크·그린·블루 다섯 색을 같은 순서, 같은 원형 견본, 같은 현재 색 표시로 한 줄에 놓는다.
- 팔레트 자체는 도구 속성 패널과 같은 다크 반투명 재질과 선택 셀을 사용한다. 원형·방사형 메뉴로 재배치하거나 색 이름·키 배지를 상시 표시하지 않는다.
- 팔레트는 포인터와 겹치지 않도록 우선 포인터 위에 띄운다. 위쪽 공간이 부족하면 아래로 보내고, 어느 경우든 오버레이의 `6px` 안전 여백 안에서 좌우 위치를 보정한다.
- 팔레트는 열린 뒤 포인터를 따라다니지 않는다. 사용자는 보이는 색 견본 하나를 클릭해 색을 확정한다.

## 열기·선택·닫기

- 색 견본을 클릭하면 즉시 색을 적용하고 팔레트를 닫는다. 별도의 확인 동작이나 토스트를 두지 않는다.
- 팔레트가 열린 상태에서 `C`를 다시 누르면 색을 바꾸지 않고 닫는다.
- 팔레트 바깥의 포인터 입력, 그리기 모드 종료, 창 포커스·문서 표시 상실은 팔레트를 닫는다.
- 열린 도구 속성 패널이 있으면 `C`가 이를 닫고 빠른 색 팔레트만 연다. 반대로 플로팅 마커의 속성 패널을 열면 빠른 색 팔레트를 닫는다. 두 색 선택 표면을 동시에 표시하지 않는다.
- 플로팅 마커를 숨긴 상태에서도 `C`로 빠른 색 팔레트를 열 수 있다.
- `⌘1`–`⌘5`와 색 이름 이니셜은 색을 고르지 않는다. 빠른 색 팔레트 안에도 색별 키보드 단축키를 두지 않는다.

## 잉크와 도구 상태

- 색 변경은 현재 도구, 현재 굵기와 잠금 상태를 바꾸지 않는다. 자유곡선·기하·텍스트·마크 삭제 어떤 도구가 활성이어도 이후 만들 마크의 잉크 속성에만 적용된다.
- 점 커서, 플로팅 마커의 현재 그리기 도구 아이콘과 다음에 여는 색 선택 표면은 즉시 새 색을 반영한다.
- 포인터를 누르고 있는 동안에는 `C`를 무시한다. 진행 중 획·기하 미리보기·이동·삭제 제스처의 색과 상태를 바꾸지 않는다.
- 텍스트 편집 세션 중에는 글자 입력이 우선하므로 `C`가 팔레트를 열지 않는다. 새 텍스트의 색은 편집 세션을 시작하기 전에 고른 현재 잉크 색을 따른다.
- 기존 텍스트 마크 교정 중에는 팔레트를 열지 않으며 마크의 원래 색을 보존한다. 교정은 내용·크기만 바꾼다는 기존 계약을 유지한다.

## 단축키 정책과 발견성

- `C`는 그리기 모드에서만 쓰는 고정 로컬 키이며 재설정하지 않는다.
- 사용자 설정 텍스트 단축키에는 수정자 없는 `C`를 배정할 수 없다. 기존 저장값이 수정자 없는 `C`이면 기본 텍스트 키 `T`로 마이그레이션한다.
- 수정자가 붙은 텍스트 단축키의 `C`는 허용한다. 빠른 색 팔레트는 수정자 없는 `C`에만 반응한다.
- 도구 속성 패널의 개별 색 견본에는 색 이름만 접근성 이름과 툴팁으로 제공한다. 제거한 `⌘1`–`⌘5`나 새 색별 키를 병기하지 않는다.
- 설정 창의 `고정 조작`에서 `도구 크기 조절 — ⌘ ±` 다음에 `색 고르기 — C`를 참고용으로 표시한다. 이 행에는 잉크색 견본을 두지 않는다.

## 연관 단축키 정리

- `E`는 더 이상 마크 삭제 도구의 고정 키가 아니며 텍스트 단축키로 배정할 수 있다.
- 순간 삭제 `⌥`과 플로팅 마커의 잠금형 마크 삭제 버튼은 유지한다.
- 자유곡선·화살표·사각형·타원·삼각형을 직접 선택하는 키보드 단축키는 추가하지 않는다. 사용 빈도가 낮은 도구 선택은 도구 속성 패널이 담당한다.

## 인수 조건

- 자유곡선 도구에서 포인터를 화면 중앙에 두고 `C`를 누르면 그 위치 위에 도구 속성 패널과 같은 가로형 5색 선택 줄이 열린다.
- 화면 위쪽에서 `C`를 누르면 팔레트가 포인터 아래로 이동하고, 좌우 모서리에서도 모든 색 견본이 `6px` 안전 여백 안에 보인다.
- 블루 견본을 클릭하면 팔레트가 닫히고 점 커서와 플로팅 마커 아이콘이 블루를 반영하며, 다음 마크만 블루로 만들어진다.
- 기하 그리기 도구 또는 잠긴 마크 삭제 도구에서 색을 골라도 현재 도구와 굵기, 잠금 상태가 유지된다.
- 팔레트를 연 뒤 `C`를 다시 누르면 색을 바꾸지 않고 닫힌다.
- 플로팅 마커를 숨겨도 `C`가 팔레트를 열고, 도구 속성 패널과 빠른 색 팔레트는 동시에 보이지 않는다.
- 진행 중 포인터 제스처에서 `C`를 눌러도 팔레트가 열리거나 진행 중 마크가 바뀌지 않는다.
- 새 텍스트와 기존 텍스트를 편집하는 동안 `C`를 입력하면 글자가 입력되고 팔레트는 열리지 않는다.
- `⌘1`–`⌘5`와 `Y/O/P/G/B`는 Arrowly의 색을 바꾸지 않는다.
- `E`는 마크 삭제 도구를 활성화하지 않으며, 설정에서 텍스트 단축키로 저장할 수 있다.
- 도구 속성 패널의 색 툴팁에는 색 이름만 보이고, 설정 창에는 `색 고르기 — C`가 재설정 필드 없이 보인다.

## 비범위

- 색별 직접 단축키, 숫자 키 매핑과 이전·다음 색 순환
- 원형·방사형 메뉴, 누른 채 가리키고 놓는 선택 제스처
- 빠른 색 팔레트 안의 키보드 탐색·확정
- 색 팔레트와 `C` 키의 커스터마이즈
- 텍스트 편집 세션 중 색 변경과 기존 마크 재색칠
- 굵기·텍스트 크기의 숫자 키 직접 선택
- 그리기 도구 직접 선택 단축키
- 5색 팔레트 자체의 변경

## 남은 위험

- 포인터 가까이 나타나는 팔레트가 설명할 화면을 가리거나 선택까지의 이동 거리를 늘리지 않는지 실제 강의 흐름에서 확인한다.
- non-activating `NSPanel`에서 수정자 없는 `C`가 한글 입력 소스와 플로팅 마커 숨김 상태에서도 안정적으로 웹뷰에 도달하는지 네이티브로 확인한다.
- 화면 모서리와 서로 다른 해상도의 다중 디스플레이에서 위·아래 전환과 좌우 보정이 포인터와 견본을 겹치게 하지 않는지 확인한다.
