# 커서 추적 확대 도구

## 목적

아래 앱이 자체 확대를 제공하지 않더라도 강사가 강의 흐름을 멈추거나 영역을 미리 지정하지 않고, 커서 주변의 작은 글자와 조작부를 뒤쪽 청중에게 크게 보여준다.

## 확정된 경험

- 확대 도구는 플로팅 마커의 1층에서 `마크 삭제 도구` 다음, 블랙보드 구분선 앞에 둔다.
- 확대 도구는 현재 그리기·텍스트·마크 삭제 도구와 상호 배타적인 잠금 도구다.
- 확대 버튼을 한 번 누르면 별도 영역 선택이나 속성 패널 없이 커서 주변 확대를 즉시 시작한다.
- 기본 확대 렌즈는 `2×`, `348×176 CSS px`, 모서리 반경 `18px`의 가로형이다. 배율 배지는 렌즈 오른쪽 위에 표시한다.
- 확대 렌즈는 커서와 간격을 두고 기본적으로 오른쪽 위를 따라간다. 공간이 부족하면 커서 반대편이나 아래로 옮기고, 마지막에는 화면 안전 여백 안으로 제한한다.
- 확대 원본 위치에는 한 개의 고대비 포인터와 렌즈가 읽는 범위를 나타내는 얇은 테두리를 표시한다. 시스템 커서와 포인터를 이중으로 표시하지 않는다.
- 가로형은 글자와 설정 행을 한 번에 읽히게 하면서 큰 카드형보다 원본 화면을 적게 가리키므로 기본 모양으로 사용한다.

## 확대 내용

- 확대 렌즈의 중심은 확대 원본 범위의 중심과 일치하고, 원본 범위는 렌즈 너비와 높이의 절반이다.
- 렌즈 내용은 커서 이동을 따라 실시간으로 갱신한다. 정지한 커서에서는 원본 범위와 렌즈 내용이 정확히 대응해야 한다.
- 투명 배경에서는 아래 앱의 현재 화면과 기존 마크를 함께 확대한다.
- 블랙보드에서는 검정 배경과 기존 마크를 함께 확대한다. 블랙보드를 켜고 꺼도 확대 도구는 활성 상태를 유지한다.
- 플로팅 마커, 도구 속성 패널, 확대 원본 표시와 확대 렌즈 자체는 확대 내용에 포함하지 않는다. 자기 자신이 반복되는 화면 되먹임을 만들지 않는다.

## 상호작용과 상태

- 확대 중 포인터 이동은 원본 위치와 확대 렌즈만 옮긴다. 클릭과 드래그는 마크를 만들거나 아래 앱에 전달되지 않는다.
- 현재 그리기·텍스트·마크 삭제 도구 중 하나를 고르면 확대를 끝내고 선택한 도구로 전환한다.
- 확대 도구를 활성화해도 기억한 현재 그리기 도구와 잉크 속성은 바뀌지 않는다.
- 확대 중 Esc를 누르면 기존 탈출 계약대로 즉시 통과 모드에 들어가고 확대를 끝낸다. 다시 그리기 모드에 들어오면 기억한 현재 그리기 도구로 복귀하며 확대를 자동 재개하지 않는다.
- 확대 활성 상태, 렌즈 위치와 원본 위치는 저장하지 않으며 실행 취소·다시 실행 이력에 들어가지 않는다.

## 화면 기록 권한

- 현재 화면을 읽을 권한이 없으면 확대 도구를 활성화하지 않고 기존 도구를 유지한다.
- macOS 권한 요청을 표시하는 동안 주석 오버레이를 일시적으로 숨기고 포인터 입력을 아래 시스템 UI에 돌려준다. 요청이 끝났을 때 그리기 모드가 여전히 유효하면 오버레이를 복원한다.
- 최초 권한 허용 뒤에는 확대 도구를 활성화하지 않고 기존 도구를 유지한 채 Arrowly 재시작이 필요하다고 안내한다.
- 권한이 필요하다는 이유와 시스템 설정을 여는 동작을 함께 제공한다. 시스템 설정을 열 때는 통과 모드로 전환해 설정 화면을 가리거나 입력을 막지 않는다. 빈 렌즈나 마지막으로 읽은 화면을 대신 표시하지 않는다.
- 확대 중 권한이 철회되거나 화면을 더 이상 읽을 수 없으면 렌즈를 즉시 닫고 기억한 현재 그리기 도구로 복귀하며 이유를 알린다.
- 권한 거부·재시작 필요·서명되지 않은 실행 파일·그 밖의 캡처 실패를 서로 다른 안내로 구분한다.
- 권한 안내나 시스템 설정을 열어도 Esc와 메뉴바를 통한 탈출 가능성은 유지한다.
- 화면 기록 권한의 네이티브 검증은 안정적으로 서명된 `Arrowly.app` 번들에서 수행한다. 빌드마다 TCC 신원이 달라질 수 있는 `tauri dev` 실행 파일은 권한 지속성의 검증 근거로 사용하지 않는다.

## 인수 조건

- 플로팅 마커에서 확대 버튼이 마크 삭제 다음과 블랙보드 구분선 앞에 보인다.
- 확대 버튼을 한 번 누르면 `2×` 가로형 렌즈와 확대 원본 표시가 커서 주변에 즉시 나타난다.
- 원본 범위 안의 글자, 기존 마크와 블랙보드가 렌즈에서 같은 중심을 기준으로 두 배 크게 보인다.
- 커서를 화면 네 모서리와 가장자리로 옮겨도 렌즈가 잘리거나 원본 범위를 덮지 않는다.
- 빠르게 커서를 움직여도 렌즈가 오래된 위치에 남거나 눈에 띄는 잔상을 만들지 않는다.
- 플로팅 마커와 렌즈를 지나가도 확대 내용에 UI가 반복해서 나타나지 않는다.
- 확대 중 클릭·드래그가 마크 생성, 마크 삭제 또는 아래 앱 입력을 만들지 않는다.
- 다른 잠금 도구를 고르면 렌즈가 사라지고 해당 도구가 즉시 활성화된다.
- 확대 중 Esc를 누르면 렌즈와 주석 오버레이가 함께 사라지고 아래 앱에 포인터 입력이 전달된다.
- 화면 기록 권한이 없거나 실행 중 철회돼도 빈 렌즈에 머물지 않고 복구 경로와 이유를 제공한다.
- 최초 권한 요청과 시스템 설정 화면에서 Arrowly가 포인터 입력을 가로채지 않으며, 허용 뒤 재시작 안내와 동작을 제공한다.

## 네이티브 검증

다음 항목은 브라우저 프로토타입이나 모의 화면으로 대체하지 않고 실제 macOS 앱에서 확인한다.

1. Retina 내장 화면과 배율이 다른 외장 화면에서 원본 위치와 `2×` 렌즈 내용이 어긋나지 않는다.
2. 전체화면 Space에서도 렌즈가 현재 화면을 읽고 화면 경계를 넘지 않는다.
3. 확대 렌즈, 플로팅 마커와 원본 표시가 화면 캡처에 섞여 되먹임을 만들지 않는다.
4. 기존 마크와 블랙보드가 렌즈 안에서 정확한 위치와 배율로 합성된다.
5. 화면 기록 권한 요청·거부·시스템 설정 이동·실행 중 철회에서 그리기 모드와 이전 도구 상태가 계약대로 복구된다.
6. 커서를 계속 움직이는 동안 아래 앱이 활성 상태로 보이고 렌즈가 강의에 방해되는 지연이나 흔들림 없이 따라온다.

## 비범위

- 원형·큰 카드형 렌즈
- `3×` 이상 배율, 배율 조절과 렌즈 크기 조절
- 렌즈 고정·직접 이동, 고정 영역 선택과 화면 전체 확대
- 확대 렌즈를 통한 아래 앱 클릭·스크롤
- 통과 모드에서 확대 렌즈 유지
- 확대 단축키와 확대 설정 저장
- DRM 등 macOS가 화면 캡처를 허용하지 않는 콘텐츠의 우회

## 가정

- 승인된 프로토타입은 도구 위치, 가로형 비율, 커서 추적과 상태 전이를 확정한다. 색·재질은 기존 플로팅 마커와 오버레이의 시각 언어를 따른다.
- v1은 강의 중 빠른 진입과 예측 가능한 출력에 집중하므로 하나의 배율과 모양만 제공한다.

## 남은 위험

- 화면 캡처와 기존 마크 합성이 Retina 배율과 서로 다른 모니터 배율에서 같은 좌표계를 유지하는지 구현 초기에 검증해야 한다.
- 화면 기록 권한의 최초 시스템 프롬프트가 강의 흐름을 끊으므로 실제 강의 전에 권한을 준비하게 하는 안내가 필요할 수 있다.
- 고해상도 화면에서 실시간 캡처와 합성이 배터리 사용량과 포인터 추적 지연에 미치는 영향을 네이티브 성능 검증으로 확인해야 한다.
- 보호된 동영상과 일부 시스템 화면은 macOS 정책에 따라 확대 내용이 비어 보일 수 있다.
